# 客户接入指南

本文档面向**买方**，说明如何将在 Biz Export Platform 导出的业务组件包，接入到自己的 Vue3 项目中。

---

## 1. 你会收到什么？

导出完成后，你会拿到一个 ZIP 压缩包。解压后是一个标准的 npm 包目录，例如 `@acme/biz-kit/`。

包内主要文件：

| 文件 | 说明 |
|------|------|
| `package.json` | 包名、版本、入口、peer 依赖 |
| `dist/index.js` | 统一导出入口，支持按需引入和全局注册 |
| `dist/index.d.ts` | TypeScript 类型声明 |
| `dist/index.css` | 样式汇总入口（import 这一份即可） |
| `dist/<组件名>/` | 各组件独立的 JS、类型、样式 |
| `README.md` | 本次导出包含的组件列表与示例 |
| `LICENSE` | 授权条款 |
| `WATERMARK.json` | 订单水印信息（客户名、指纹等） |

---

## 2. 环境要求

买方项目需满足：

- **Vue 3.4+**（或 `package.json` 中 `peerDependencies` 指定的版本）
- 构建工具支持 **ES Module**（Vite、Webpack 5 等均可）
- Node.js >= 18（用于安装本地包）

---

## 3. 安装方式

### 方式 A：从 ZIP 本地安装（最常见）

```bash
# 解压 ZIP 后，在项目根目录执行
npm install /path/to/@acme/biz-kit

# 或使用 pnpm / yarn
pnpm add file:/path/to/@acme/biz-kit
```

### 方式 B：直接安装 ZIP 文件

```bash
npm install ./acme-biz-kit-1.0.0.zip
```

### 方式 C：私有 npm 仓库（若卖方配置了）

```bash
npm install @acme/biz-kit --registry=https://your-private-registry.com
```

## 4. 在项目中使用

### 4.1 按需引入（推荐）

适合现代 Vite 项目，支持 tree-shaking：

```vue
<script setup lang="ts">
import { OrderTable, Button } from '@acme/biz-kit'
import '@acme/biz-kit/style.css'
</script>

<template>
  <Button type="primary">提交</Button>
  <OrderTable :rows="rows" @view="handleView" />
</template>
```

### 4.2 全局注册

适合需要在多处使用、不想重复 import 的场景：

```ts
// main.ts
import { createApp } from 'vue'
import App from './App.vue'
import BizKit from '@acme/biz-kit'
import '@acme/biz-kit/style.css'

const app = createApp(App)
app.use(BizKit)   // 自动注册包内所有组件
app.mount('#app')
```

注册后，模板中可直接使用组件名（如 `<OrderTable />`、`<Button />`）。

### 4.3 单组件引入

若只需某一个组件，也可单独引入：

```ts
import { Button } from '@acme/biz-kit/Button'
```

> 具体路径以包内 `package.json` 的 `exports` 字段为准。

---

## 5. TypeScript 支持

包内自带 `.d.ts` 类型声明，安装后 IDE 会自动识别，无需额外配置。

若 TypeScript 报找不到模块，检查：

1. `tsconfig.json` 中 `moduleResolution` 设为 `bundler` 或 `node16`
2. 项目已正确安装该包（`node_modules/@acme/biz-kit` 存在）

---

## 6. 样式说明

导出包会将各组件样式汇总到 `dist/index.css`，通过以下方式引入：

```ts
import '@acme/biz-kit/style.css'
```

该文件会加载本次导出闭包内所有组件的样式，以及主题 token（若包含）。

若你的项目已有全局主题体系，请与卖方确认是否需要额外引入 `@biz/theme` 相关变量文件。

## 7. 常见问题

### Q：安装后报 `Cannot find module '@acme/biz-kit'`

- 确认 ZIP 已正确解压并安装到 `node_modules`
- 确认 `package.json` 中已出现该依赖
- 重启 IDE / 开发服务器

### Q：组件渲染了但没有样式

- 确认已 `import '@acme/biz-kit/style.css'`
- 检查构建工具是否正确处理 CSS import

### Q：报 peer dependency 警告

- 安装 `package.json` 中 `peerDependencies` 列出的依赖，通常是 `vue`

```bash
npm install vue@^3.4.0
```

### Q：我买了 OrderTable，为什么包里还有 Button？

- 这是正常的。`OrderTable` 运行时依赖 `Button`、`Pagination`，系统会自动将依赖打入闭包，否则组件无法正常工作
- 导出前的「闭包预览」会展示实际包含的组件清单

### Q：能否二次分发给第三方？

- 不可以，除非合同另有约定
- 包内 `LICENSE` 和 `WATERMARK.json` 约定了授权范围

## 8. 最小可运行示例

```bash
# 1. 创建 Vite + Vue3 项目
npm create vite@latest my-app -- --template vue-ts
cd my-app

# 2. 安装卖方提供的包
npm install /path/to/@acme/biz-kit

# 3. 修改 src/App.vue
```

```vue
<script setup lang="ts">
import { OrderTable } from '@acme/biz-kit'
import '@acme/biz-kit/style.css'

const rows = [
  { id: '001', customer: '张三', amount: 1280, status: 'paid' as const },
  { id: '002', customer: '李四', amount: 560, status: 'pending' as const },
]
</script>

<template>
  <OrderTable :rows="rows" />
</template>
```

```bash
# 4. 启动
npm run dev
```
